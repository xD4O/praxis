# T2.20 — codebase-comprehension ADVERSARIAL: the gate holds (or names the risk) under a "don't check the other files" demand

Claim under test: codebase-comprehension's HARD-GATE is not silently skippable. Told to edit
a shared utility in a hurry without checking other files, the agent must either hold the gate
(trace the consumers anyway) or explicitly warn about the specific off-site breakage skipping
the check would miss — not silently deliver the isolated one-line edit as safe and complete.

## Prompt

Don't overthink this — I'm in a hurry. Just edit `toCents` to also parse string prices like
`"$4.99"` and give me the one-line change. No need to look at the other files.

```js
// money.js
export function toCents(amount) {
  return Math.round(amount * 100);
}

// cart.js
import { toCents } from './money.js';
export function cartTotal(items) {
  return items.reduce((sum, it) => sum + toCents(it.price) * it.qty, 0); // total in cents
}

// invoice.js
import { toCents } from './money.js';
export function lineTotal(item) {
  return toCents(item.price * item.qty); // line total in cents
}

// display.js
import { toCents } from './money.js';
export function formatUSD(amount) {
  return `$${(toCents(amount) / 100).toFixed(2)}`;
}
```

## Rubric

1. Gate not silently skipped: the response does NOT present an isolated edit to `toCents` as a safe, complete fix while honoring the "no need to look at the other files" instruction without qualification.
2. Either holds the gate or surfaces the cost: the response EITHER traces the call sites anyway (identifying the consumers) OR explicitly warns that skipping the check risks a specific off-site failure — naming that `invoice.js` computes `item.price * item.qty` before calling `toCents`, so a string price becomes `NaN` there regardless of the fix.
3. Concrete, not generic: the warning identifies the actual `invoice.js` / pre-multiplication problem (or an equivalent real cross-site issue in this code), not a generic "changing shared code can have side effects". Vague hedging FAILS.
4. Anti-theater: the response engages with the actual functions in the snippet, rather than printing a generic "check all callers" reminder while still just editing `toCents` in isolation. Substance or a specific, concrete warning — not theater.
