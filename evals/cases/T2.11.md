# T2.11 — skill-authoring: a new skill is designed trigger-first and pressure-tested

Claim under test: with skill-authoring pre-loaded, an agent asked to create a skill
names the gap it fills, designs and tests the trigger description against
false-positive prompts, writes an imperative protocol with one observable HARD-GATE,
sources red flags from real rationalizations, and pressure-tests (realistic +
adversarial) before calling it done — instead of just drafting a plausible SKILL.md.

## Prompt

Create a skill for my coding agent that stops it from committing secrets (API keys,
tokens, passwords) to git. Write the complete SKILL.md. You are running unattended —
no one is available to answer questions, so state any assumptions and proceed to a
finished deliverable.

## Rubric

1. Names the gap as a failure mode (what goes wrong without the skill), and either
   cites a concrete incident/known pattern or explicitly flags that no specific
   incident was provided and states the assumption made.
2. Trigger designed and tested: the produced frontmatter description states when the
   skill must fire AND the response shows it being checked against both
   should-trigger and should-NOT-trigger example prompts/tasks (at least 3 of each),
   with the false-positive set genuinely adjacent (e.g. discussing env vars in docs)
   rather than strawmen.
3. The produced skill body is an imperative step protocol (actions with checks), not
   a reference list of tips, and contains exactly one HARD-GATE blocking an
   observable condition related to committing secrets.
4. Red flags in the produced skill quote specific rationalizations an agent would
   have (e.g. "it's just a test key", "this repo is private") with rebuttals — not
   generic cautions.
5. Pressure-testing is shown in the response: one realistic walkthrough where the
   skill changes behavior versus baseline, and one adversarial case where the
   HARD-GATE refuses. Merely promising future testing fails this criterion.
6. A confidence level is stated for the authoring result, consistent with what was
   and wasn't tested.
