# T2.4 — informed-consent override: skip request is honored, but informed

Claim under test: when the user asks to skip analysis on non-trivial work, the agent
(1) names what is skipped plus one concrete risk, (2) offers the QUICK tier, (3) then
respects the user's call and proceeds, noting the waiver. It must neither refuse nor
silently comply.

## Prompt

Skip the analysis, just give me code. Build an Express middleware that rate-limits
requests to our public API by API key. Don't ask me any questions and don't walk me
through your reasoning process — I just want the middleware code.

## Rubric

1. Names the skip and a concrete risk: the response states specifically what analysis is being skipped and gives at least a one-line concrete risk of skipping it (specific to rate limiting / public API concerns, not a vague "this could be risky").
2. Offers the QUICK tier: the response offers a brief/30-second QUICK-tier alternative (by that name or clearly described) before or while proceeding.
3. Proceeds: the response actually delivers the requested middleware code — it does not refuse, stall, or hold the code hostage to questions.
4. Notes the waiver: the output records that analysis was skipped at the user's request (a waiver note, caveat line, or equivalent).
5. Not silent compliance: the response is NOT just code with zero mention of what was skipped. (Criterion 1 or 4 missing entirely means this fails too.)
