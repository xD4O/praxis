# T2.5 — QUICK tier: small reversible choice gets a tiered brief answer

Claim under test: the QUICK depth tier produces a 3-5 line structured answer with a
recommendation and confidence — brief, but still tiered reasoning, not the full
protocol and not an unstructured one-liner.

## Prompt

Quick gut-check, keep it brief: for a small internal CLI tool's config file, should
I use YAML or TOML? It's easily changed later — I just want a sanity check, not a
deep analysis.

## Rubric

1. Brevity: the substantive answer is roughly 3-8 short lines — not a full protocol run, not multi-section framework output.
2. Clear recommendation: one option is clearly recommended.
3. Confidence stated: an explicit confidence level (HIGH/MEDIUM/LOW) appears.
4. Real reasoning: at least one concrete trade-off or reason specific to config files / CLI tools backs the recommendation — not a bare verdict.
5. No ceremony: no spec mirror, no problem-classification section, no multi-framework analysis, no long numbered protocol steps.
